# Melete — Study Abroad Interview Practice Platform

> Confident Answers Come From Real Knowledge, Not Memorized Scripts.

**Melete** is an intelligent, high-fidelity interview-practice platform designed for students preparing for university admissions and student visa interviews across the globe.

---

## Key Features

- **Personalized Intake Tracks**:
  - **UK Universities**: Pre-CAS Interview simulation (syllabus, modules, living expenses).
  - **UK Visa / Home Office**: UKVI Credibility Interview simulation (genuine student rules, funding proof).
  - **US Consular / F-1 Visa**: Direct under-60-second response drills (Section 214(b) intent to return, Form I-20).
  - **Other Destinations**: Custom pathways for Germany (APS & Sperrkonto), Canada (GIC & IRCC ties), Australia (Genuine Student), Ireland, France, and beyond.
- **Dynamic 60fps Audio Visualizer**: Real-time dual harmonic sine wave and particle spectrum canvas powered by the HTML5 Canvas API and Web Speech synthesis.
- **Diagnostic Performance Reports**: Instant composite scores, 4 regulatory credibility pillar metrics, and question-by-question verbatim transcripts with feedback.
- **Resource Repository**: 33 curated preparation guides across 4 categories with instant modal reading drawers.
- **FAQ Knowledge Base**: 20 comprehensive questions with real-time keyword search, category filters, and butter-smooth 60fps CSS grid accordions.
- **Melete Design System v1.0**:
  - Accent Color: Royal Blue (#1A3C8F, hover #0d2a60)
  - Typography: Serif headlines (Playfair Display), Sans-serif body (Inter)
  - Border Radius standard: 4px
  - Fluid mobile-first responsiveness across all viewports (320px to 1440px+)

## Getting Started

### Local Setup
No build tools, Node, or NPM dependencies required. Simply serve the directory with any static HTTP server:

`powershell
# Python 3
python -m http.server 8080
`

Then visit **http://localhost:8080** in your browser.

Or on Windows, simply double-click start.bat.
